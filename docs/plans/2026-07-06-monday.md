## 4. Liquidity design (full text: IMPROVEMENTS.v4 strategy #4)

Roles — keep them distinct:

| Signal | Question it answers | Weighting |
|---|---|---|
| delta | what will move (exposure selector) | unchanged — already drives margin strike targeting |
| day volume | can we exit at fair prices *today* | heaviest for margin (must exit by 12:55) |
| open interest | does a standing market exist | heavier for cash (overnight holds); stable intraday → safe to floor-gate |
| bid/ask sizes | is the quoted spread real | execution tactics + phantom-quote defense |

Rollout — one step at a time so each change stays attributable:

1. **Log-only (live Monday).** Two collection points:
   ```bash
   # chosen contract per group per cycle — incl. spread + sizes (quote-fetched)
   grep '"scope":"manage-allocation-candidate"' <out.log> | jq '{dayVolume, openInterest, bidSize, askSize, spreadPct}'
   # the considered set (top 6 sorted candidates) — vol/OI/ivx/delta from the chain
   # sample; no spread/sizes for alternatives (would cost per-candidate quote fetches)
   grep '"scope":"top-candidate-considered"' <out.log> | jq '.candidates[] | {sym, dte, vol, oi}'
   ```
   The chosen-candidate stream sets the step-2 floor thresholds (we gate what we'd buy); the considered-set stream is what the step-3 *scoring* design needs, since scoring discriminates between alternatives.
2. **Floor gates on new entries** — `STRATEGY_MIN_OPEN_INTEREST` (start ~100, set from step-1 data; ships with `.env.example` + README entries) and a phantom-quote guard: sizeless quote while the market is open ⇒ don't trust this cycle's spread-gate pass.
3. **Scoring + tactics** — replace the decorative `meetsVolumeRequirement` flag and last-place volume tiebreak with a liquidity score among spread-passing candidates (log-scaled volume + OI; volume-weighted for margin, OI-weighted for cash); teach the tick-chaser to respect sizes (don't chase an ask showing less size than the order; prefer patient mid on thin bids for closes).

Hard rule for every gate: sampling covers only ~ATM strikes in the target DTE window — **unknown degrades gracefully (pass + log), never treated as zero.** Otherwise we recreate the IV-gate silent-blocking bug in a new costume.
